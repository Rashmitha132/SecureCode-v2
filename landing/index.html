Got Questions?

Frequently Asked Questions

Technical details regarding models, local privacy, deployment options, and AST graph parsing.

How does the Graph Neural Network (GNN) analyze code ASTs?
SecureCode v2 parses incoming code into an Abstract Syntax Tree (AST). We extract node features and control/data-flow edge adjacencies. A 3-layer Graph Convolutional Network (GCN) embeds these relationships into PyTorch tensors, outputting defect classification probabilities without relying on brittle regexes.
Does my proprietary code leave my local environment?
No. The Regex detector, Shannon Entropy engine, PyTorch GNN ML microservice, and MySQL feedback database execute 100% locally. The optional semantic analyzer uses your private Groq API key or can be routed to an on-premise local LLM.
Which programming languages are currently supported?
SecureCode v2 provides full 4-tier hybrid scanning and code generation for Python, JavaScript, TypeScript, Go, Rust, Java, C++, PHP, and Ruby.
